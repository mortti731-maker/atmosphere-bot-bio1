# 🌟 Telegram Bio Bot

**Создайте красивую био-страницу для своего Telegram профиля!**

## 📌 О проекте

Этот бот позволяет пользователям Telegram создавать персональные био-страницы с:
- 🖼️ **Круглым аватаром** с анимацией свечения
- 🎨 **Фоновым изображением** на выбор
- ✨ **Красивыми анимациями** выезда и эффектами
- 📱 **Адаптивным дизайном** для мобильных устройств
- 🔗 **Уникальными ссылками** для каждого пользователя

## 🚀 Быстрый старт

### 1. Локальный запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/telegram-bio-bot.git
cd telegram-bio-bot

# Установите зависимости
npm install

# Создайте .env файл (или используйте существующий)
cp .env.example .env

# Запустите в режиме разработки
npm run dev

# Или в production режиме
npm start
```

### 2. Использование бота

1. Откройте Telegram и найдите вашего бота
2. Отправьте команду `/start`
3. Используйте `/setbio` для создания био-страницы
4. Следуйте инструкциям бота
5. Получите ссылку с помощью `/mybio`

## 🛠️ Технические детали

### Структура проекта

```
telegram-bio-bot/
├── index.js              # Основной файл бота и сервера
├── public/               # Статические файлы
│   ├── bio-template.html # Шаблон био-страницы
│   └── ...               # Другие статические файлы
├── .env                  # Переменные окружения
├── package.json          # Зависимости и скрипты
├── deploy.sh             # Скрипт развертывания
└── README.md             # Документация
```

### Технологии

- **Node.js** - Серверная платформа
- **Express** - Веб-фреймворк
- **node-telegram-bot-api** - Telegram Bot API
- **dotenv** - Управление переменными окружения
- **HTML5/CSS3** - Интерфейс био-страницы

### Переменные окружения

| Переменная       | Описание                          | Пример                          |
|------------------|-----------------------------------|---------------------------------|
| TELEGRAM_TOKEN   | Токен вашего Telegram бота        | `8934177430:AAE...`             |
| DOMAIN           | Домен вашего сервера              | `your-bot.onrender.com`         |
| PORT             | Порт сервера                      | `3000`                          |
| USE_WEBHOOK      | Использовать вебхуки              | `true` или `false`              |
| WEBHOOK_URL      | URL для вебхука                   | `https://domain.com/webhook`    |

## 🌐 Развертывание на хостинге

Проект готов к развертыванию на бесплатных хостинг-платформах:

### 🎯 Render.com (Рекомендуется)

1. **Создайте аккаунт** на [render.com](https://render.com)
2. **Создайте новый Web Service**
3. **Подключите GitHub репозиторий**
4. **Настройте переменные окружения** из `.env` файла
5. **Установите команды**:
   - Build: `npm install`
   - Start: `npm start`
6. **Разверните**

### 🛤️ Railway.app

1. **Создайте аккаунт** на [railway.app](https://railway.app)
2. **Создайте новый проект**
3. **Импортируйте репозиторий**
4. **Добавьте переменные окружения**
5. **Разверните**

### 🔄 Cyclic.sh

1. **Создайте аккаунт** на [cyclic.sh](https://cyclic.sh)
2. **Подключите GitHub**
3. **Выберите репозиторий**
4. **Добавьте переменные окружения**
5. **Разверните**

## 🔧 Настройка вебхуков

Для постоянной работы бота настройте вебхук:

```bash
curl -F "url=https://your-domain.com/webhook" \
     https://api.telegram.org/botYOUR_TOKEN/setWebhook
```

Или через браузер:
```
https://api.telegram.org/botYOUR_TOKEN/setWebhook?url=https://your-domain.com/webhook
```
